# Chess-Bot

A chess bot for [Lichess](https://lichess.org) built on the official Bot API and a UCI engine
such as Stockfish. It accepts challenges and keeps playing until you stop it, locally or in the cloud (Docker).

The bot code lives on the [`lichess-bot`](../../tree/lichess-bot) branch, including setup and
cloud deployment instructions.

## Fair play

Use it only on a Lichess **BOT account**, which is clearly labelled as a bot. Do not use it to
play people who don't know they are facing an engine, and do not use it on sites that forbid bots.
